# Airbnb

StayNest is an Airbnb-style marketplace built with Express, EJS, MongoDB, Mongoose, and Tailwind CSS.

## Features

- Guest search and filtering by location, dates, guests, price, and sort
- Date-aware booking flow with unavailable date checks
- Saved homes and trips
- Host dashboard with listing stats, upcoming bookings, and calendar blocking
- Multi-image listings with amenities, house rules, capacity, and pricing

## Scripts

```bash
npm install
npm run seed
npm run dev
```

For production-style start:

```bash
npm run build:css
npm start
```
